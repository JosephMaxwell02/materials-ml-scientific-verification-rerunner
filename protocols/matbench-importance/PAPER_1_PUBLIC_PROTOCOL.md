# Paper 1 Public Protocol

Four official Matbench regression tasks used 142 Magpie descriptors, official five-fold
splits and a frozen CPU MLP (128/64). Fitted permutation importance was compared with
complete retraining after individual and declared-group removal. The related evidence
package reconstructs accepted readouts from derived tables. This separate verification
rerunner additionally performs one exact full-fold baseline and genuine retrained-
removal fit from locally generated public features. It does not rerun all 6,880
scientific units or expose the production runtime.
